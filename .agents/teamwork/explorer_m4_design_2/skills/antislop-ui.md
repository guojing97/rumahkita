# Antislop UI Skill Reference
Source: /Users/mac/.gemini/config/skills/antislop-ui/SKILL.md

Core Methodology:
- No generic AI tells: avoid blue-purple gradients, excessive glassmorphism, pill everything, soft blurry floating shadows, ambient glow everywhere, decorative status dots, fake terminal windows, emoji decoration.
- Color palette: strict cap at 2-3 core colors + 1 accent (#C8F169 as neon accent, #FFFDF7 base, #171717 ink/border).
- Neo-brutalism specifics: unblurred hard drop shadow (4px 4px 0px #171717), 2px solid #171717 borders, 8px/12px intentional radii.
- App & Dashboard hygiene: no invented metrics, no generic 4-stat-card defaults unless directly serving the user's immediate decision; no fake data/John Doe; purposeful empty and loading states.
- Motion: purposeful tactile feedback on click (translate-x-0.5 translate-y-0.5 shadow-none), no endless loops/pulsing.
